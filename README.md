# מערכת בחירת תמונות לסטודיו צילום

Next.js 14 + Supabase + Vercel. הכול על שכבות חינמיות.

## התקנה (בערך 10 דקות, פעם אחת)

### 1. Supabase (בסיס נתונים + אחסון + התחברות)
1. פתחי חשבון חינמי ב-supabase.com ← **New project**.
2. **SQL Editor** ← New query ← הדביקי את כל `supabase/schema.sql` ← **Run**.
3. **Authentication → Providers → Email**: כבי את **Confirm email** (כדי שהרשמה של צלמת תעבוד מיד, בלי מגבלת המיילים של התוכנית החינמית).
4. **Project Settings → API**: העתיקי `Project URL`, `anon public` ו-`service_role`.

### 2. מייל (חינם, דרך Gmail)
חשבון Google ← אבטחה ← אימות דו-שלבי ← **סיסמאות אפליקציה** ← צרי סיסמה. זה ערך `SMTP_PASS`.
ללא הגדרה הכול עובד, פשוט לא יישלחו מיילים (ואפשר להעתיק את פרטי הלקוחה ידנית).

### 3. Vercel (אירוח)
1. העלי את התיקייה ל-GitHub (repository פרטי).
2. ב-vercel.com ← **Add New → Project** ← בחרי את ה-repository.
3. תחת **Environment Variables** הוסיפי את כל המשתנים מהקובץ `.env.example`.
4. **Deploy**. זהו.

### 4. אחרי הפריסה
- היכנסי ל-`https://האתר-שלך/studio` ← הרשמה ← גלריה חדשה.
- אחרי שכל הצלמות נרשמו, אפשר לסגור הרשמה חדשה: Supabase ← Authentication ← Sign In / Providers ← כיבוי **Allow new users to sign up**. לקוחות ממשיכות להיווצר דרך המערכת.

## איך זה עובד
- **פרטיות:** ה-bucket פרטי. קריאה, כתיבה ומחיקה של קבצים מותרות רק לצלמת הבעלים ולקוחה של אותה גלריה (RLS על `storage.objects`). התצוגה משתמשת בקישורים חתומים לשעה, שנוצרים רק אחרי הזדהות. אין כתובת ציבורית לקבצים.
- **הצפנה:** Supabase מצפין אחסון ומסד נתונים במנוחה (AES-256) ואת התעבורה (TLS).
- **העלאה:** הדחיסה, הקטנה (עד 1400px) וסימן המים נעשים בדפדפן של הצלמת, 6 תמונות במקביל. הקובץ המקורי לא עולה לשרת.
- **מכסה:** נאכפת גם בבסיס הנתונים (trigger), לא רק בממשק.
- **אישור סופי:** נועל את הגלריה ושולח מייל לצלמת עם שמות הקבצים המקוריים, השיבוץ בעמודים וההערות.
- **מחיקה אוטומטית + Keep-Alive:** `vercel.json` מפעיל פעם ביום את `/api/cron`. הוא מבצע שאילתה קטנה (מונעת השעיית בסיס הנתונים) ומוחק גלריות וקבצים שחלפו 30 יום מיצירתן.

## מגבלות החינם
- Supabase: 1GB אחסון. תצוגה מקדימה שוקלת בערך 100–250KB, כלומר כמה אלפי תמונות בו-זמנית. המחיקה החודשית שומרת על מקום.
- Vercel Hobby: Cron פעם ביום (מספיק כאן). לשימוש מסחרי תנאי השירות של Hobby דורשים לבדוק את התוכנית.
- Gmail SMTP: עד כ-500 מיילים ביום.
